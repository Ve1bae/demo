## 3. 失败记录

### 3.1 第一次执行

| 项目 | 结果 |
| --- | --- |
| 执行时间 | 2026-08-26 16:09（北京时间） |
| 测试总数 | 5 |
| 通过 | 2 |
| 失败 | 1 |
| 错误 | 2 |
| 失败原因 | 新建直播间分支实际只调用 `insert`，测试错误地要求 `updateById`；异常分支中的公共 Mockito 桩未被使用，触发严格桩校验。 |
| 处理措施 | 将更新断言移动到“复用已有直播间”场景，并将分支型测试桩设置为宽松模式。 |
