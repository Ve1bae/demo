# UC-03 视频推荐微服务接口契约

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 服务 | `video-service` |
| 功能 | UC-03 浏览推荐视频 |
| 版本 | v0.2 |
| 更新日期 | 2026-09-03 |
| 当前分支 | `microservice` |
| 实现状态 | 推荐逻辑已合入完整 video-service；user-service 偏好接口已实现并完成本地 Compose 联调 |

本文档只描述 UC-03 推荐功能以及它依赖的用户偏好数据，不覆盖视频上传、详情、评论、弹幕和直播接口。

## 2. 服务信息

| 项目 | 当前独立运行 | 集成时要求 |
| --- | --- | --- |
| 默认地址 | `http://127.0.0.1:8082` | 由 Compose、Kubernetes 或网关统一配置 |
| 基础路径 | `/api/videos` | 保持不变 |
| 推荐接口 | `GET /api/videos/recommend` | 保持不变 |
| 健康检查 | `GET /actuator/health` | 探针和网关使用实际部署端口 |
| 登录身份 | `X-User-Id` 请求头 | 数字用户编号；游客不传 |
| 响应格式 | `application/json` | UTF-8 |

当前整合服务、Compose、Kubernetes、健康检查和测试脚本统一使用 `8082`；后续与组长分支整合时继续保持同一端口约定。

## 3. 通用响应格式

推荐接口使用统一响应体：

```json
{
  "code": 200,
  "message": "success",
  "data": []
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `integer` | 成功为 `200`；参数错误为 `400`；服务异常为 `500` |
| `message` | `string` | 结果说明；成功时为 `success` |
| `data` | `array/object/null` | 成功数据；错误时为 `null` |

健康检查是 Actuator 原生格式，不使用上述业务响应体：

```json
{
  "status": "UP"
}
```

## 4. 推荐接口

### 4.1 基本定义

| 项目 | 内容 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/videos/recommend` |
| 登录身份 | 可选请求头 `X-User-Id` |
| 成功状态 | HTTP `200`，`code=200` |
| 空结果 | HTTP `200`，`data=[]` |
| 参数类型错误 | HTTP `400`，`code=400` |

### 4.2 查询参数

| 参数 | 类型 | 必填 | 默认值 | 约束和行为 |
| --- | --- | --- | --- | --- |
| `page` | `integer` | 否 | `1` | 小于 `1` 时按 `1` 处理；无法转换时返回 `400` |
| `pageSize` | `integer` | 否 | `12` | 限制为 `1` 至 `50`；超过 `50` 按 `50` 处理；无法转换时返回 `400` |
| `categoryId` | `integer` | 否 | `0` | 大于 `0` 时按分类筛选；小于等于 `0` 查询全部分类 |
| `keyword` | `string` | 否 | 空字符串 | 去除首尾空格后，对标题、作者、描述和标签执行不区分大小写的包含匹配 |

游客请求示例：

```text
GET /api/videos/recommend?page=1&pageSize=12&categoryId=0&keyword=
```

登录用户请求示例：

```text
GET /api/videos/recommend?page=1&pageSize=12
X-User-Id: 930001
```

### 4.3 响应字段

`data` 是推荐视频数组。当前 UC-03 返回字段如下：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `long` | 视频编号 |
| `videoId` | `long` | 与 `id` 相同，供前端兼容 |
| `title` | `string` | 标题 |
| `description` | `string/null` | 描述 |
| `coverUrl` | `string/null` | 封面地址 |
| `playUrl` | `string/null` | 播放地址 |
| `videoUrl` | `string/null` | 原始视频地址 |
| `author` | `string/null` | 作者名称 |
| `userId` | `long/null` | 作者用户编号 |
| `categoryId` | `integer/null` | 分类编号 |
| `tags` | `string/null` | 数据库存储的原始标签 |
| `tagList` | `array<string>` | 分隔、去重、最多保留 8 个标签 |
| `duration` | `integer/null` | 视频时长，单位为秒 |
| `status` | `string` | 只返回 `public` 视频 |
| `playCount` | `integer/null` | 播放量 |
| `likeCount` | `integer/null` | 点赞量 |
| `favoriteCount` | `integer/null` | 收藏量 |
| `commentCount` | `integer/null` | 评论量 |
| `sources` | `object` | 清晰度到播放地址的映射，当前默认填充 `720P` |
| `defaultQuality` | `string` | 默认清晰度，默认值为 `720P` |
| `authorInfo` | `object/null` | 作者扩展信息 |
| `authorInfo.userId` | `long` | 作者用户编号 |
| `authorInfo.following` | `boolean` | 当前用户是否关注该作者；游客为 `false` |
| `createdAt` | `string/null` | ISO 日期时间 |
| `updatedAt` | `string/null` | ISO 日期时间 |

成功响应示例：

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 930301,
      "videoId": 930301,
      "title": "UC03 Campus Music",
      "description": "Campus music test video",
      "coverUrl": "",
      "playUrl": "https://example.test/videos/campus-music.mp4",
      "videoUrl": "videos/campus-music.mp4",
      "author": "UC03 Author A",
      "userId": 930101,
      "categoryId": 3,
      "tags": "campus music",
      "tagList": ["campus", "music"],
      "duration": 120,
      "status": "public",
      "playCount": 100,
      "likeCount": 0,
      "favoriteCount": 0,
      "commentCount": 0,
      "sources": {
        "720P": "https://example.test/videos/campus-music.mp4"
      },
      "defaultQuality": "720P",
      "authorInfo": {
        "userId": 930101,
        "following": false
      },
      "createdAt": "2026-08-31T09:00:00",
      "updatedAt": "2026-08-31T09:00:00"
    }
  ]

```

### 4.4 推荐排序规则

先筛选 `status=public` 的视频，再执行分类和关键词筛选，之后计算分数并分页。当前分数规则为：

```text
score = playCount
      + likeCount * 20
      + favoriteCount * 30
      + commentCount * 10
      + followedAuthor ? 10000 : 0
      + sum(matchedInterestScore * 10)
      - viewedVideo ? 200 : 0
```

排序优先级：

1. `score` 降序。
2. 分数相同时按 `createdAt` 降序。
3. 创建时间仍相同时按 `id` 降序。

分页发生在筛选、评分和排序之后。页码超出范围时返回空数组，不返回错误。

## 5. 用户偏好接口（已联调契约）

### 5.1 当前状态

UC-03 客户端预留的接口为：

```text
GET /api/users/{userId}/preferences
```

当前 `user-service` 使用 `/api/user` 控制器前缀，并已提供偏好聚合接口。video-service 通过 HTTP 调用该接口；两个服务不直接访问对方数据库。`viewedVideoIds` 当前由 user-service 返回空集合，最终观看历史仍由 video-service 的 `view_history` 表维护。

### 5.2 建议请求

| 项目 | 内容 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/users/{userId}/preferences` |
| `{userId}` | 必填，数字用户编号 |
| 成功状态 | HTTP `200` |
| 失败状态 | 用户不存在可返回 HTTP `404`；服务不可用由 video-service 降级处理 |

### 5.3 建议响应

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "followedAuthorIds": [930101, 930102],
    "interests": {
      "music": 80,
      "campus": 50
    },
    "viewedVideoIds": [930301]
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `followedAuthorIds` | `array<long>` | 当前用户关注的作者编号 |
| `interests` | `object<string, integer>` | 标签及兴趣分值；缺失或负值按 0 处理 |
| `viewedVideoIds` | `array<long>` | 可选的已观看视频编号集合 |

`viewedVideoIds` 只是兼容字段。观看历史的最终来源仍是 video-service 自有 `view_history` 表，不能删除本地查询。

### 5.4 降级规则

- 游客不调用用户偏好接口，直接使用空偏好。
- 用户偏好接口超时、连接失败、返回无法解析或返回空数据时，使用空偏好继续推荐公开视频。
- 偏好服务异常不应导致推荐接口返回 `500`。
- Compose 联调配置已设置 `USER_SERVICE_ENABLED=true`。在 user-service 不可用、超时、返回非预期内容时，video-service 自动使用空偏好继续返回公开视频。

## 6. 健康与版本接口

### 6.1 健康检查

```text
GET /actuator/health
```

正常响应：HTTP `200`，响应体包含 `status=UP`。容器编排的 readiness 和 liveness 检查都应使用该地址，并跟随最终部署端口。

### 6.2 信息接口

```text
GET /actuator/info
```

用于查看服务名和版本。生产环境只暴露 `health`、`info` 等必要端点，不暴露数据库密码、环境变量和其他敏感配置。

## 7. 数据归属

| 数据 | 所属服务 | video-service 的使用方式 |
| --- | --- | --- |
| `video` | video-service | 查询公开视频、分类、标签和统计字段 |
| `view_history` | video-service | 查询用户已观看视频并执行降权 |
| 用户基本信息 | user-service | 不复制用户表；由其他接口按需提供 |
| 关注关系 | user-service | 通过用户偏好接口获取作者编号集合 |
| 兴趣标签 | user-service | 通过用户偏好接口获取标签及分值 |

video-service 不直接读取 `sys_user`、`user_follow`、`user_interest`，也不执行跨数据库 JOIN。

## 8. 配置项

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SERVER_PORT` | `8082` | 服务监听端口；集成时由组内统一 |
| `DB_URL` | 本地 MySQL `video_db` | JDBC 数据库连接串 |
| `DB_USERNAME` | `root` | 数据库用户名 |
| `DB_PASSWORD` | 空 | 数据库密码，必须通过环境变量或 Secret 注入 |
| `USER_SERVICE_ENABLED` | `false` | 是否调用用户偏好服务 |
| `USER_SERVICE_BASE_URL` | `http://user-service:8081` | 用户服务地址；路径以最终契约为准 |
| `SPRING_SQL_INIT_MODE` | `never` | 是否执行 Spring SQL 初始化 |

示例：

```powershell
$env:SERVER_PORT = "8082"
$env:DB_URL = "jdbc:mysql://localhost:3306/video_db"
$env:DB_USERNAME = "root"
$env:DB_PASSWORD = "<本机测试密码>"
$env:USER_SERVICE_ENABLED = "false"
```

不得把实际密码、Token 或密钥写入代码、测试数据、接口示例和 Git 提交。
