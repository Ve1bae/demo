| UC-06    | 发送视频弹幕 | 注册用户   | 用户播放视频时发送弹幕                   | 用户正在播放视频，视频存在且可访问     | 输入弹幕内容和颜色；系统保存视频时间点；播放器按时间轴展示弹幕。 | 弹幕为空、内容过长或发送失败时提示修改或重试。               | 弹幕记录包含视频、时间点、内容和颜色；重新播放到对应时间点时可显示弹幕。 |

### 3.3 软件需求的分析模型

#### 3.3.1 UC-01 视频上传系统顺序图

代码段

```mermaid
sequenceDiagram
    actor Creator as 内容创作者
    participant Web as 前端Web应用
    participant System as 航音视频系统
    participant Storage as MinIO对象存储
    participant DB as MySQL数据库

    Creator->>Web: 选择视频文件并提交上传信息
    activate Web
    Web->>Web: 前端校验（登录态、格式、大小、标题非空）
    Web->>System: POST /video/upload（文件 + 标题 + 描述 + 封面）
    activate System
    System->>System: 校验用户身份与文件合法性
    System->>Storage: 上传视频文件和封面
    activate Storage
    Storage-->>System: 返回对象访问地址（playUrl / coverUrl）
    deactivate Storage
    System->>DB: 保存视频标题、描述、作者、播放地址
    activate DB
    DB-->>System: 保存成功（videoId）
    deactivate DB
    System-->>Web: 返回上传成功和视频信息
    deactivate System
    Web-->>Creator: 提示上传成功，跳转视频详情
    deactivate Web
```
