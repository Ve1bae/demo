- `UNIT-*`：单元测试；`API-*` / `TC-*`：集成或 HTTP API 测试；`E2E-*` / `BROWSER-*`：端到端测试。
- 具体总数、环境、原始输出和失败记录见各用例测试报告；本表只提供总览入口。
- “待复验”是事实状态，不代表功能不存在；完成后应把结果、时间和证据路径补回对应报告。
