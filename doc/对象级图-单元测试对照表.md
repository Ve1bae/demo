# 《航音视频》对象级图与单元测试对照表

## 1. 对照范围和判定规则

本表以《软件详细设计说明书》的 UC-01 至 UC-10 图为设计输入，将图中的参与对象、系统操作、关键返回值和异常/分支，映射到现有后端单元测试的具体测试方法。

- **直接覆盖**：测试通过 Mock/断言直接验证图中的对象调用、参数、返回值或状态变化。
- **部分覆盖**：测试覆盖该步骤的业务结果，但未验证图中全部对象交互或调用顺序。
- **未见对象级单测**：当前没有对应 Mockito/对象级单元测试；可能有 MockMvc、API、后端 E2E 或浏览器测试，但它们不计为对象级单元覆盖。
- UC-02、UC-05、UC-08、UC-09 虽然标题写为活动图，但图内包含 Controller、Service、Mapper 等对象/系统操作，本表按这些节点映射。
- 行号对应当前工作区版本；测试方法均位于 `backend/src/test/java`。

## 4. 统计结论与补测优先级

| 结论项 | 统计结果 | 说明 |
| --- | --- | --- |
| 对象级图/活动图覆盖较完整的用例 | UC-03、UC-07 | UC-03 覆盖 Controller 参数、Mapper 查询条件、个性化数据源与排序；UC-07 覆盖 DTO 校验、落库、SRS 地址、更新、VO 返回和复用分支。 |
| 已覆盖核心 Service 行为但图中存在遗漏节点 | UC-02、UC-04、UC-05、UC-06、UC-09、UC-10 | 主要遗漏观看历史/兴趣写入、Controller 前置校验、WebSocket 广播和前端播放器动作。 |
| 缺少专门对象级单元测试的用例 | UC-01、UC-08 | UC-01 目前只有 Web 层 MockMvc；UC-08 目前依赖 API/E2E 与浏览器测试。 |
| 图与实现不一致，应先修订设计或实现 | UC-01、UC-02、UC-04 | UC-01 上传编排归属不一致；UC-02 图为物理删除而实现是逻辑删除；UC-04 图中播放量 Mapper 与实现使用 Mapper 不一致。 |

建议补测顺序：

1. UC-08：为 `LiveRoomServiceImpl.getRoom` 添加房间存在/不存在、主播查询、播放地址和清晰度 VO 的 Mockito 单测。
2. UC-09、UC-10：为 `LiveInteractWebSocketHandler` 添加连接、弹幕广播、点赞广播和异常消息的对象级测试。
3. UC-04：为首次观看/重复观看的 `ViewHistoryMapper` 和 `UserInterestMapper` 写入增加 Mock 验证，并统一播放量 Mapper 设计。
4. UC-01：将上传编排下沉到 Service 后补充 Service 对 MinIO、转码、保存、失败回滚顺序的 Mockito 单测；或修订对象图使其与 Controller 编排实现一致。
5. UC-02：决定采用逻辑删除还是物理删除；据此同步活动图、资源清理实现和测试。
