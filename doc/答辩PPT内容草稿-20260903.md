# 《航音视频》最终答辩 PPT 内容草稿

建议时长：15 分钟（项目与架构 4 分钟、现场演示 7 分钟、问答 4 分钟）  
代码版本：`microservice` 分支；现场演示前先确认使用的 commit SHA

## 第 1 页：项目与改造目标（约 30 秒）

- 沿用上学期航音视频系统，不是新做系统。
- 保留 `monolith-start` 作为改造前基线。
- 改造目标：保持 UC-01 至 UC-10 主要业务可用，并增加可验证的微服务部署、扩缩容、故障处理和性能对比。

## 第 2 页：系统架构与服务边界（约 1 分钟）

- 前端 -> Nginx API Gateway -> 三个业务微服务。
- `user-service`：账户、关注、兴趣偏好。
- `video-service`：视频、推荐、播放、互动、MinIO。
- `live-service`：直播间、SRS、WebSocket 互动。
- 三个独立 MySQL 数据库；不跨服务直接联表。

## 第 3 页：UC-03 推荐实现（约 1 分钟）

- 公开视频筛选、分类、关键词、排序和分页。
- 热度分、时间分、关注作者加分、兴趣标签加分、观看历史降权。
- video-service 通过 HTTP 获取 user-service 偏好。
- user-service 异常时自动使用空偏好，不影响推荐接口返回。

## 第 4 页：播放器、视频互动和直播（约 1 分钟）

- VideoPlayer 支持视频详情、播放量、评论、点播弹幕和互动状态。
- live-service 提供直播间生命周期、SRS 地址和 WebSocket 弹幕/点赞。
- 现场只演示已在当前版本真实复验的流程；SRS 专项状态以最终运行记录为准。

## 第 5 页：CI/CD（约 1 分钟）

- push 到 `microservice` 后执行三个服务 Maven 测试。
- Compose 启动三数据库、MinIO、SRS、三个服务和网关，执行 HTTP/浏览器 E2E。
- 测试失败由 `needs` 阻断后续镜像和部署。
- push job 构建 SHA 版本镜像，Kind 部署并执行健康检查，现场展示当前 Actions 记录和 Artifact。

## 第 6 页：三类测试（约 1 分钟）

- 单元/API：user `9/9`、video `24/24`、live `18/18`，合计 `51/51`。
- HTTP/API：用户、视频互动、UC-07 真实链路。
- Playwright：UC-03 `5/5`，直播非 SRS `7/7`。
- 展示测试报告中环境、命令、断言、失败数和原始报告位置。

## 第 7 页：Kubernetes 与健康检查（约 45 秒）

- 展示 namespace、Deployment、Service、Pod、探针和资源限制。
- 展示 `kubectl get deployment,pods,hpa -n hangyin`。
- 展示 rollout 成功和 `/gateway/health`、推荐、直播接口结果。

## 第 8 页：HPA 自动扩缩容（约 1 分钟）

- 运行 `scripts/hpa-load-test.ps1` 对推荐接口施加负载。
- 现场展示 video-service 副本数从 `1 -> 2 -> 3`。
- 停止负载后展示回到 `1`，同时展示 HPA 样本和资源数据。

## 第 9 页：故障处理（约 1 分钟）

- 停止 user-service。
- 推荐接口通过空偏好降级，仍返回 HTTP 200；live-service 不跟随崩溃。
- 恢复 user-service 后再次请求，个性化调用恢复。
- 展示 `evidence/fault-drill/` 中请求 JSON、服务状态和 fallback 日志。

## 第 10 页：单体/微服务性能对比（约 1 分钟）

- 固定视频详情、评论列表、播放计数三个接口。
- 并发 `1/10/50/100`，每档重复 3 次，条件相同。
- 展示吞吐量、平均响应时间、P95、错误率、CPU 和内存。
- 结论限定为当前机器、当前数据和当前资源配置；不宣称微服务在所有场景都更快。

## 第 11 页：需求到测试追溯（约 45 秒）

- 展示 `REQ -> UC -> 系统图 -> 组件图 -> 对象图 -> 代码 -> 测试` 的追溯表。
- 重点讲 UC-03、UC-07、UC-09 三个代表用例。
- 其余用例仍保留自动回归入口，接受现场抽查。

## 第 12 页：交付与风险说明（约 30 秒）

- 展示 README、Dockerfile、数据库脚本、Kubernetes、测试和压力结果目录。
- 答辩前补入真实 Actions 链接、站会/看板截图、成员确认材料。
- SRS 浏览器专项必须在 FFmpeg 可执行环境复验后更新状态。

## 现场命令卡

```powershell
docker compose -f docker-compose.microservices.yml -p hangyin-microservices ps
Invoke-RestMethod http://127.0.0.1:8080/gateway/health
kubectl get deployment,pods,hpa -n hangyin
.\scripts\hpa-load-test.ps1 -DurationSeconds 120
.\scripts\fault-drill-microservices.ps1
```

命令仅在相应 Docker/Kubernetes 环境已启动并确认口令后执行；不要在 PPT 中放入真实密码。
