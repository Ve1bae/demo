# UC-03 浏览推荐视频微服务测试报告

## 1. 测试结论

本次测试针对 `video-service` 中已迁移的 UC-03 推荐接口执行了服务层单元测试、控制器单元测试和 Spring API 集成测试。三类测试共 33 项，全部通过，构建结果为 `BUILD SUCCESS`。

本次没有把原单体前端浏览器 E2E 计入微服务测试结果。因为当前 video-service 没有独立前端或网关入口，原单体 E2E 仍验证旧的单体路径，不能作为微服务迁移后的 E2E 证据。

## 3. 测试范围

测试覆盖以下需求分支：

- 游客访问推荐接口。
- 登录用户读取关注作者和兴趣标签。
- 已观看视频降权。
- 公开视频过滤。
- 分类和关键词组合筛选。
- 推荐分数排序和分页。
- 空结果返回。
- 非法页码和非法用户标识返回 HTTP 400。
- 视频字段补充、标签解析和边界值处理。

## 8. 测试记录和复现方式

在包含 `video-service` 目录的工作区执行：

```text
mvn -B -ntp -f video-service/pom.xml test
```

测试报告原始文件由 Maven 生成在：

```text
video-service/target/surefire-reports/
```

其中包含三个测试类对应的 XML 和 TXT 结果。`target/` 属于构建生成目录，已在 `.gitignore` 中排除，不应提交到远程仓库。

## 9. 限制和后续验证

- H2 API 测试验证了 Spring MVC、服务层和 JDBC 查询链路；正式联调仍需使用隔离的 `video_db` MySQL 数据库复验 SQL 兼容性。
- 用户服务的实际接口路径和偏好响应字段需要与组内 user-service 统一后，再增加真实 HTTP 客户端契约测试。
- 当前没有独立 video-service 前端或网关，因此尚未执行迁移后的浏览器 E2E。网关接入完成后，应至少复验首页推荐、搜索、登录个性化推荐和空结果四个场景。
- Docker、Kubernetes、公共 CI/CD 和其他用例不属于本次 UC-03 测试报告范围。

## 10. 结论

在当前实现范围内，UC-03 推荐服务的业务规则、HTTP 参数处理、数据库读取、跨服务偏好降级和主要异常分支均已通过测试。该结果可作为 video-service 后续 MySQL 联调、网关接入和端到端回归的基线。
