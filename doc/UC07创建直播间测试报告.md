## 8. 端到端测试说明

已新增端到端测试脚本 `scripts/uc07-e2e.mjs`。该脚本不使用 Mock，不绕过控制器，直接从 HTTP 接口入口执行 UC-07 业务流程：

1. `POST /api/live/rooms` 创建直播间。
2. `GET /api/live/rooms/{roomId}` 查询创建后的直播间。
3. `GET /api/live/rooms?page=1&pageSize=50` 验证直播间出现在列表中。
4. `POST /api/live/rooms/{roomId}/close` 关闭直播间。
5. 使用空标题验证异常流程。
6. 不传 `X-User-Id` 验证未登录异常流程。

脚本适合放入流水线，失败时退出码为 `1`，可以阻断发布或部署。默认访问 `http://localhost:8080`，可通过环境变量调整：

| 环境变量 | 说明 | 默认值 |
| --- | --- | --- |
| `UC07_E2E_BASE_URL` | 后端服务地址 | `http://localhost:8080` |
| `UC07_E2E_USER_ID` | 测试主播用户编号 | `42` |
| `UC07_E2E_REPORT` | JSON 测试报告输出路径 | `backend/target/e2e-reports/uc07-e2e-report.json` |

流水线推荐先启动数据库和后端服务，再执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run-uc07-tests.ps1
```
